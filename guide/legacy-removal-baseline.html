T01 / T02 迁移基线与执行记录 ​

历史方案/基线记录，保留当时结论供审计。旧引擎、模式选择与浏览器文字回退 已由 T20 删除；当前 API、字体能力与示例以迁移指南为准。

基线代码：fd11752e（迁移前），分支：refactor/canvas-render-engine。 本记录只验收 T01/T02；不代表 legacy 已删除、默认引擎已切换或 Bunny 下载已实现。

固定环境和样本 ​

共享数据：tests/fixtures/migration/documents.ts，每次创建独立模型，避免布局回写污染。 视口 1366×720，DPR=1，页面 480×640，边距四边 32，字号 16，缩放 1，关闭增量。 字体：仓库内 public/fonts/NotoNaskhArabic-Regular.ttf，400 normal。 SHA-256：67b5a525a661b607971fbd3f96a81b89d3a768e74534fca84f18ac97e6fab72f。 单测使用真实字体二进制和真实 HarfBuzz WASM，但 Canvas 是 mock；其宽度不能当作浏览器像素结果。 浏览器使用同一二进制并注册 FontFace，不依赖系统 Arabic 字体或外网下载；数据 URI 图片无需外网。 字体未承诺覆盖所有脚本，中文/emoji/缺字能力由后续字体任务独立验收。

两种现有模式分别冻结，不要求 legacy 与 HB 几何相等。单测保留可读的行宽/高/基线、 分页方向和尺寸；全部位置坐标取三位小数后用 SHA-256 固定，缺失位置索引单独显示。 不包含随机 ID、时间和内部字形缓存。测试正常运行不得使用 --update。 确认行为变更时先检查具体差异并增加针对性断言，再人工审核更新；禁止批量重录掩盖失败。

真实浏览器测试同时检查真实 Worker 的字数和异步保存、HarfBuzz WASM 实例化、 字体 HTTP 成功、PRINT 导出每页有可见墨迹，并截图供人工比较。 截图是审查产物，未引入跨机器像素阈值；打印对话框与物理打印尚属 T22 的人工验收。

已知问题与边界（不是本轮新增回归） ​

  • paragraphs 的 HarfBuzz 布局在元素索引 116 缺少位置，legacy 无此缺口。 快照显式记录为 missing=[116]，不得把空洞过滤掉后宣称几何完整。T17 修复后增加命中断言。
  • 当前 HarfBuzz 模式仍有 BrowserTextShaper、浏览器文字绘制和对象/表格 legacy 回退。 样本通过不等于纯 HB 通过；engine 标记可供后续核对，但不是删除审计证据。
  • 当前纯文本增量有适用条件，复杂结构仍全量重排；默认配置仍保留旧模式。
  • 迁移前库 ESM 输出可生成，但 UMD 因 harfbuzzjs 顶层 await 失败；T02 删除 UMD 目标。
  • 消费端原有声明泄漏 @/editor/interface/Print、未发布 CSS 和缺失字体类型依赖； T02 修复了相对引用、类型侧 CSS import、发布依赖及 Emscripten 引用。
  • 构建仍有 harfbuzzjs 的 Node module 浏览器外部化分支、无效动态分块和大 chunk 提示； 通过真实浏览器消费验证其可运行，不把警告当成 UMD 失败。

T02 发行契约 ​

  • build.lib.formats=['es']，构建前清理 dist，保留 sourcemap 和声明。
  • 删除 UMD main；保留 module，使用标准 types；exports 根入口只有 types/import， 不提供 require/default 条件。唯一附加公开子路径是 package.json。
  • README 与中英文入门文档审计未发现已声明的内部子路径 API；具名导出保留根入口。 dist/*、src/* 深路径不再允许。此项和删除 require 均为破坏性发行变更。
  • 发布预处理不再要求 UMD，也不删除声明所需依赖；发现旧 UMD/CJS 文件时拒绝发布。
  • test:package 先 npm pack，再解包到独立临时工程，严格类型检查（skipLibCheck 未开启）、 验证 CommonJS 解析被拒绝、运行发布预处理及残留文件拒绝检查、构建独立 Vite 消费端， 检查相对 chunk；仅从锁文件已安装的声明依赖离线链接，未执行公共 npm 安装。
  • --serve 提供 /native/（原生 import map、无消费端打包）和 /bundled/（Vite）两种 非根路径页面。Worker 与 WASM 由发行 JS 内联携带，字体由消费工程相对路径提供， 不假设必须存在独立 .wasm 文件，也不承诺本轮实现默认字体包。

重复执行 ​

bash
pnpm exec vitest run tests/core/migration/baseline.test.ts
pnpm exec vite --host 127.0.0.1
# 另一终端，检查源代码样本
pnpm run test:migration:browser --browser electron

# 构建发行包并生成独立消费页面
pnpm run lib
pnpm run test:package -- --serve
# 另一终端，检查 tarball 的两种消费模式
pnpm run test:migration:browser --browser electron \
  --config baseUrl=http://127.0.0.1:4179 --env package=true

源代码人工入口：http://127.0.0.1:3000/canvas-editor/tests/fixtures/migration/index.html。 参数：sample=...&engine=legacy|harfbuzz，默认 paragraphs/harfbuzz。 截图输出 cypress/screenshots，保持环境一致再做视觉比较。 测试专用 Cypress 配置不纳入既有应用部署 E2E（发行 app 不包含测试页面）。
