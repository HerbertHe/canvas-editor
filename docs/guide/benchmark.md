## 测量口径

同机 Apple M1 Pro / 8 logical CPUs / 16 GiB，Darwin 25.4.0，Node 24.19.0。字体为 NotoNaskhArabic-Regular.ttf，SHA256 `67b5a525a661b607971fbd3f96a81b89d3a768e74534fca84f18ac97e6fab72f`。

历史 Chrome 为 155.0.8059.85，本次为 155.0.8059.86。因此为同机同负载历史趋势，**不是浏览器版本完全相同的严格 A/B**，不能将全部时差唯一归因于代码。

标准负载为 middle / paging / history on / 段落缓存 off / DPR 1 / warmup 1 / 2Hz × 10s，每配置 20 次操作。初始基线一轮，修复前后各三轮；固定 trial 0 比较，不挑最快轮，三轮范围另列。输入取 input handler，删除取 keydown handler。单位为 ms，降低比例为 `(修复前 - 本次) / 修复前`，负数表示耗时增加。

geometry 为事件到几何提交的代理值，offer→geometry 含驱动排队，均不等于屏幕呈现延迟。阶段 inclusive 时间存在嵌套，不可相加。

## IME-09：提交、取消与查询闭环

2026-11-02 增补。本项验证编辑语义，不修改先前计时数据或源码哈希，
不从历史数据推断本次延迟/FPS 收益。

最终同步回调发生在历史提交、旧合成状态清理后；回调中撤销或开启新合成
不会与上一条事务交叉。取消从恢复点还原复杂范围和输入样式，避免留痕重复、
控件占位符丢失；只渲染一次，不发最终内容提交事件。控件占位符的历史修复
避免弹掉上一条历史。简单同起点替换只保存原始片段和最终文本，历史 delta 大小
不再随已消费的中间拼音版本数增长，Worker 仍接收全部已落实版本。

同步/异步导出统一 graffiti 字段；异步查询保留调用时快照，后续编辑不改写结果。
浏览器回放对照 baseline/sync/worker × 短段、100/1000 段、长段、单元格，
另覆盖禁止 Worker 的工具查询回退。可用的正文 Worker 检查镜像、版本、排空；
表格仍同步回退。延迟真实 Worker 布局结果到最终提交后再放行，检查文档及
