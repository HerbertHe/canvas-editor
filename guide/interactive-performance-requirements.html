Canvas Editor 交互性能优化需求 ​

第一批交付聚焦五页示例中最容易感知的三处延迟。中文输入时，后台字数、目录和批注刷新应避开预编辑。普通正文改动应尽量复用同一文档内未变化的表格、控件和页面位置。可见页面应按用户当前的编辑和滚动位置及时更新。离屏缓存和 Worker 绘制根据主线程绘制、光栅化及内存的复测结果决定是否立项。

当前表现与目标 ​

三组对照使用同一台 Apple M1 Pro 和无头 Chrome 158.0.8127.36，视口 1366 × 720，DPR 1。 各自的内置示例保留各版本的文档，当前示例为 5 页，上游为 2 页。 共享百段样本使用相同正文和纸张设置。

首期目标是让五页示例中安全的普通正文编辑接近共享百段文档的交互量级，同时收紧居中标题的 IME 尾延迟，减少快速滚动、缩放时的白屏或旧内容。全文布局、选区和像素的对照以当前构建的完整路径为准，性能距离以上游在线示例为参考。

交付顺序 ​

优先级需求决定是否继续的证据
P0合成期间延后非交互查询预编辑期间额外的同步刷新和整篇重绘消失，选字后侧栏恢复到最新结果
P0复杂文档中的普通段落增量提交稳定编辑由整篇重排变为局部重排，按键耗时下降，分页与位置对照通过
P1单行居中标题的 IME 局部预览居中位置和候选窗锚点准确，帧调度尾延迟下降
P1编辑页与视口内脏页优先绘制编辑页和滚入视口的页面更早更新，连续操作没有新增空白帧
按测量立项局部重绘、离屏缓存、Worker 绘制高 DPR 或密集页的绘制仍占明显时间，单项对照改善端到端延迟

先补齐分阶段诊断，再拆分变更做对照。后台刷新与增量布局可以独立交付。视口调度同时依赖准确的脏页、当前页号和几何版本。表格内部编辑、长段回退和跨页提交沿用历史路线图里的专项入口。 历史路线图

P0 合成期间延后非交互查询 ​

用户正在连续输入拼音时，示例的字数、目录、批注列表及连接线可以短暂沿用最近一次稳定结果。选字提交、取消或因业务命令结束合成后，自动补一次最新状态。上一轮编辑留下的定时器也要在开始实际查询前判断合成状态，仅在创建定时器时检查会漏掉本次复现。

  1. 将内容变化和滚动触发的后台刷新汇总为待更新状态。合成开始后暂停发出这些查询，并让已发出的异步结果在回写 DOM 前再次校验当前状态和请求版本。
  2. 用实例生命周期内的合成状态判断是否可执行查询，复用现有合成会话或只读诊断。合成结束后从最新文档读取一次，覆盖合成期间累积的刷新请求。实例销毁、示例重置时清理预约和迟到回调。
  3. 保留用户主动操作的语义。复制、保存、打印、导出及调用方主动查询继续按现有合同取得所需的最新文档和几何。后台查询对应的延后策略放在示例或宿主调度层。

验收　复现删除后立即输入拼音、预编辑期间滚动、连续选字、Esc 取消和页面销毁。进入合成后的后台字数、目录和批注查询次数为零，由这些任务触发的立即整篇绘制为零。合成结束后，最终内容、字数、目录和批注位置一致，每类待刷任务只消费最新状态。单独记录主动查询场景，确保原有行为通过回归。 示例刷新调度 · 公开查询提交规则

P0 复杂文档中的普通段落增量布局 ​

在带表格和控件的文档中输入或连续删除时，只要本次编辑发生在普通正文，且受影响的布局能在可验证的边界收敛，就应复用无关内容。首批支持分页、单栏、正文非结构性文本编辑，优先打通已有五页示例。表格或控件出现在文档其他位置时，只要它的布局输入和位置可以验证，就可沿用已有布局。

首批支持与复用边界 ​

  1. 以本次事务的脏区定位最早受影响的段落，复用未受影响的前缀。检查编辑范围是否触及结构节点、浮动排除区、表格片段或控件范围。
  2. 复用现有段落索引、流状态检查点和位置块。首批只放行编辑段落重新排版后行数、行高、结束页号、列号、纸张方向及纵向游标稳定的操作。后缀沿用前，检查页布局、可用宽度、字体版本、浮动排除及相关对象依赖。页眉、页脚含复杂对象时，先覆盖它们自身布局和占用高度稳定的场景。
  3. 即使后缀页面的视觉位置不变，插入和删除仍可能平移逻辑索引。用现有来源索引投影更新光标、命中、选区、批注位置和导出所读的范围。表格和控件若缺少可靠的索引投影或依赖校验，回退到正式布局。
  4. 下一批扩展到换行或跨页后可向后收敛的场景。从最早受影响位置重算，直至新的流状态及依赖和旧检查点重新一致。遇到结构编辑、字体切换、缩放、分栏变更或校验失败时，由完整路径计算。对回退按具体原因计数，便于判断下一批该扩大哪类覆盖。

正确性与性能验收 ​

  • 同一份五页示例选择一处普通正文，连续输入、Backspace 和 Delete。对已确认稳定的操作，记录受影响段落、重排页、复用页与整篇回退次数。首批支持用例应命中增量路径。
  • 加入行尾换行、删除换行、临近分页边界、普通段落与表格相邻的输入回放。每次提交后比较完整路径和优化路径的页号、行断点、文字矩形、光标、选区与表格片段。连续删除保持每键正确提交，撤销重做维持当前分组语义。
  • 建议首批将稳定正文的按键 P95 压到 16 ms 以内，随后争取达到现有输入预算 handler P95 ≤ 8 ms、geometry P95 ≤ 32 ms。正式门槛应在同构建的未优化对照复测后确认。 增量布局入口 · 流状态检查点

P1 单行居中标题的 IME 预览 ​

单行居中标题支持局部预览。宽度随预编辑文本变化时，按新宽度重新居中。下划线、光标及隐藏输入代理的候选窗锚点使用同一套临时几何。提交和取消分别落到正式文本和合成前状态。

  • 使用现有 HarfBuzz 临时布局。安全条件包括行数、行高、基线和页号稳定，以及版心、字体版本和相关样式一致。新预编辑序号替代未显示的旧状态，迟到结果按预编辑序号和文档版本校验。
  • 旧字形区域与新居中位置都要刷新。首期可以沿用编辑页整页绘制。若后续采用局部清理，边界取旧行、新行及下划线实际绘制区域的并集，并覆盖抗锯齿边缘。
  • 文字跨行、分页变化、复杂双向文本或对象排除不满足校验时，使用正式布局。检查退格清空、取消、替换选区、切换候选、缩放、滚动和字体到达期间的锚点。

验收　内置标题的稳定测试用例连续预编辑时，整篇排版次数为零，正式提交单独计量。建议首批将该用例从预编辑到第二次 rAF 的 P95 控制在 50 ms 以内。短正文和原有回退场景应同时复测，并用真实系统输入法观察候选窗、正文光标、选字及取消。 预览条件 · 预览绘制

P1 优先绘制用户正在看的页 ​

沿用已有脏页、分页 Canvas 和缩放时保留旧位图的机制。分页编辑时，优先绘制视口里的编辑页，其次绘制其他当前可见脏页，余量用于滚动方向上接近视口的脏页。编辑页不在视口时，实际可见页优先。视口判断覆盖窗口和配置的滚动容器。

  1. 区分实际可见页和观察器预取范围。已有观察器使用 200 px 扩展边界，扩展区进入事件用于准备低优先级绘制。调度时使用最新的滚动位置和已提交布局，避免为位置读取引入每帧全量扫描。
  2. 用页身份、文档和几何版本、缩放及 DPR 判断一次绘制是否仍有效。每页保留最新待画状态。滚动、缩放和新输入可以重新排序旧任务，页移除或销毁时清理观察和排队状态。
  3. 可见编辑页进入本次可用绘制机会。其余可见页随帧预算分批完成，低优先级页通过等待时间或进入视口提高优先级。尺寸调整和立即重绘放在同一次任务里。绘制完成前可以保留旧位图，滚入视口后尽快替换。
  4. 保留连续页、打印和显式像素读取的完成语义。同步读取和导出可刷新待绘页。滚动或缩放不得使旧几何、旧字体或迟到的异步图片覆盖最新页面。

验收　包含视口同时可见两页、在第二页输入、快速换向滚动、连续缩放、嵌套容器、高 DPR 和导出。记录编辑页及其他可见页的首次绘制次序、输入到编辑页完成绘制的延迟、进入视口后等待多久更新，以及空白和旧画面持续帧数。对有多页待画的用例，编辑页优先且其他可见页最终刷新。程序化坐标与导出像素通过完整路径对照。 当前视口与懒绘制 · 缩放绘制入口

离屏绘制的立项条件 ​

先在上述改动完成后复测高 DPR、图片密集页和重复水印，分别记录 Canvas 指令提交、浏览器光栅化、合成、绘制面积和可见页端到端延迟。将同一个慢样本沿时间线核对。若绘制成本可解释剩余延迟，再按成本来源选择一个小范围对照。每个实验都与相同绘制范围的主线程实现比较。

方案第一批实验范围扩大范围的条件
静态内容离屏缓存重复水印小图块或确有重复成本的静态页层。按资源、样式、缩放、DPR 及相关字体版本失效创建和合成的总成本下降，可见页延迟下降，活跃缓存和内存峰值在实测预算内
编辑行局部清理与重绘行位置和页尺寸稳定的普通正文或标题。按旧、新绘制边界恢复背景并重画相交内容同浏览器、同 DPR 的完整重绘像素对照通过。复杂装饰、图片叠层及跨页用例能可靠回退
Worker 离屏绘制固定一个可见的高绘制负载页。提交已验证几何的紧凑绘制数据，每页只接受最新任务数据准备、传输、排队、光栅化和提交的全链路有可重复的改善。覆盖字体和尺寸失效、Worker 中断、导出与销毁

缓存方案按像素面积和累计字节限制存活位图，分别记录活跃画布面积、JS heap 及可获得的浏览器进程内存。若 Worker 方案选择直接转移页面 Canvas，需在该元素建立绘制上下文前决定后端，并演练故障后重建主线程 Canvas、恢复页号和观察器的流程。 HTML 标准的 Canvas 转移规则

场景主要指标必查的正确性
五页示例的普通正文和共享百段样本输入、Backspace、Delete 的 handler、geometry、编辑页绘制 P50/P95/P99/max，整篇重排次数字素删除、逻辑索引、光标、选区、撤销重做和分页
五页示例的居中标题、短正文及中长段 IME合成事件到布局和第二次 rAF、编辑页绘制等待、预览命中与回退、整页重绘次数选字、取消、清空、重复输入去重与候选窗跟随
表格、控件相邻段落与复杂回退流检查点复用、受影响页数、回退原因、长任务表格片段、选区命中、批注位置及混排方向
滚动、连续缩放、DPR 1/2、打印和导出可见页等待、空白或旧画面持续、绘制面积、活跃像素及内存尺寸、DPR、字体变化、页身份、导出像素和资源释放
  • 每个变更固定文档、编辑位置、字体资源、视口、缩放、DPR、浏览器版本及预热方式。用同一源码的开关 A/B，至少三轮轮换顺序，保留慢样本。每档补足事件样本并报告数量。IME 会话独立重置位置和内容，按接收、合并、绘制及结束时处置分别统计更新。
  • 定位耗时用阶段插桩，发布判断用关闭插桩的计时和视觉证据。逐键记录接收、几何提交、绘制开始和完成。rAF、Canvas 绘制完成以及浏览器 trace 共同解释延迟，系统输入法候选窗和真实可见刷新由人工录屏验证。Chrome、Firefox 和 WebKit 分别采集浏览器结果，真实候选窗覆盖实际 macOS 和 Windows 输入法。
  • 开关按独立功能灰度。首批以正确性对照通过、目标场景的改善超过运行波动、短文档和回退路径没有稳定可复现退化作为扩大范围的依据。遇到几何、像素、候选窗或导出回归，回退相应功能开关，保留该轮数据分析原因。
  • 每项交付附可复现命令、源码和资源哈希、两组分布、失败用例与回退情况。公开基准继续保留上游、初始迁移和当前三组对照。独立实验的原始记录供工程复现。 现有基准入口 · 回归与验收入口
