功能差异与对比边界 ​

对比固定为上游 1.0.5、 main 提交 1d7cd1a7。 这不是对上游未来能力的判断。“无同等管线”不代表浏览器本身不能显示对应文字。

能力上游基线本 fork 0.1.0
文字排版 / 绘制Canvas 浏览器测量和文字绘制HarfBuzz 唯一整形与原生布局；Canvas 字形轮廓绘制
字体输入浏览器字体选择与回退注册 TTF/OTF/WOFF/WOFF2；按实际字体 face 管理覆盖与轮廓
缺字检测无同等显式覆盖报告管线覆盖报告、变化事件、缺字方框、页面和控制台提示
基本字体自动下载无同等 Bunny 下载管线默认开启、可运行时关闭、失败重试；支持离线手动字体
RTL / 双向与复杂文字无同等 HarfBuzz cluster/caret 几何管线统一字形/cluster/caret、视觉导航与逻辑删除；不是所有语言均已完整验证
初始化同步构造Editor.create() / editor.ready，包含失败状态与销毁清理
增量排版已有行级增量能力原生段落布局复用，再重新计算分页与位置；不承诺更快

表格、控件、分页、段落间距、批注、留痕、宏等上游已有继承并适配，不作为本 fork 原创新功能宣传
插件生态上游维护的外部插件可作为参考；需逐项验证字体、异步初始化及 API 兼容性

Canvas-only 支持范围 ​

本版本页面绘制固定使用 Canvas，没有可切换的 renderer 配置。 SVG 页面实现、SVG 后端选项与独立 SVG 文档导出均未提供，且暂缓实施。 不要配置 renderer: 'svg'；旧 renderMode / textEngine 也不可使用。 公式、图标、插入的 SVG 图片与字形缓存中的 SVG path 数据属于资源， 不表示存在 SVG 页面引擎，不需要为了暂停页面引擎而删除这些资源。 打印采用 Canvas 图片链路，不承诺可搜索的矢量 PDF。

SVG 评估仅作为未来方案保存，所有 SVG-01～12 任务尚未启动。T23/T24 已于 2026-10-22 完成验收，详见最终验收。 实测仍有明显性能成本，增量不一定更快；SVG 评估与性能目标不作为已实现功能宣传。

安装、迁移与本地示例 ​

sh
npm uninstall @hufe921/canvas-editor
npm install @herberthe/canvas-editor@0.1.0
typescript
import Editor from '@herberthe/canvas-editor'

const editor = await Editor.create(
  document.querySelector<HTMLDivElement>('.canvas-editor')!,
  { main: [{ value: '周末计划 · Weekend plans · خطة نهاية الأسبوع' }] }
)
  • 同步 new Editor() 后必须等待 editor.ready 再执行修改或几何命令。
  • 删除旧文字引擎配置和旧枚举；更新所有根包导入，禁止内部深路径导入。
  • 默认开启 Bunny 基本字体下载；离线环境设置 autoDownloadFonts: false 并提供字体。
  • 基本字体不保证罕见字、所有语言/样式或彩色 emoji 覆盖；缺字提示仍可能出现。
  • 用相同字体重新验收分页、行宽、选区、控件和插件；不保证与浏览器字体度量一致。
  • Node.js 开发环境要求 >=24.13.1，浏览器与构建器需支持 WASM、Worker 和顶层 await。

npm run dev 启动本 fork 的日常生活多语种示例，npm run docs:dev 启动本地文档。 独立包消费示例见 examples/esm-fonts。上游网站、插件和历史发布文档属于原项目， 不能作为本 fork 已上线站点或兼容承诺。

发布与许可证 ​

先运行 npm run lib、npm run test:package、npm run docs:build， 再用 npm pack --dry-run 检查包内容。实际发布需使用有 @herberthe scope 发布权限的 npm 账号，命令为 npm publish --access public；这是一项独立发布操作。 T23/T24 已完成，结果见最终验收；每次新发布仍需重新执行适用的检查。
