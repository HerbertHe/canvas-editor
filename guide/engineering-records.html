验收与历史记录 ​

日常接入以快速上手、当前架构、渲染管线和 API 参考为准。本页保留设计与分阶段验收的出处；这些记录中可能描述当时尚未完成的迁移状态，不能直接当成当前公开接口。

当前结论 ​

T1–T24 的 legacy 移除与 HarfBuzz-only 迁移已完成；T23/T24 于 2026-10-22 完成最终回归。Canvas-only 与 ESM-only 是当前发布约束。原生增量布局仍有明显成本，不承诺提速，剩余性能问题不会因测试通过自动关闭。

  • 最终验收：环境、用例、包消费、跨浏览器、内存和性能结果。
  • 原生回归说明：测试入口与定向覆盖。
  • 迁移任务表、最初移除方案：阶段范围和验收索引。
  • 原始基线：对照数据，保留历史，不代表当前功能。

排版与字体实施记录 ​

  • HarfBuzz 整形、字形绘制、布局协议、几何。
  • 字体解析、覆盖诊断、字体下载、Bunny 适配、ready。
  • 原生段落、对象、表格、文档流。
  • 页眉页脚、辅助文字、交互几何、模型分离、原生增量、唯一引擎。
  • 公开 API 迁移、RTL 设计、RTL 后续事项、主干功能整合记录。

SVG 暂缓方案 ​

HarfBuzz 到 SVG 的评估是未来方案，不是当前实现。SVG-01～12 尚未启动；用户当前应使用 Canvas。不要根据历史图或设计稿添加不存在的 renderer 配置。

维护文档 ​

中英文首页和主指南保持同步；中文验收原始数据作为工程证据保留，英文页面会明确链接过去。修改实现时同步更新对应主指南；历史测量、版本和提交基线不应为了匹配现状而重写。新图表使用 Mermaid，构建时检查语法，站点客户端渲染。发布方法见文档部署。
