# 中文输入法性能优化任务

更新日期：2026-11-03。IME-01–13 已实现，IME-14 自动验收和发布门禁已实现；
本轮没有真实系统输入法记录，按用户要求保留人工待验收及发布 hold。
本计划针对连续拼音预编辑的刷新问题，不将普通输入 Benchmark 的结果当作 IME 性能证据。

优化前的默认路径会在每次合成 input 中删除旧预编辑文本、插入新文本并同步 render；
布局 Worker 对 composition 保留同步回退。`deferredPaint` 合并绘制，尚未合并布局。
Demo 仅显式开启 `incrementalCompute`，尚未使用 `sync` profile。

## 统一验收规则

- 固定文档、中文字体及字体哈希、浏览器、OS、输入法、缩放、DPR、历史和预热。
  同环境、同事件序列至少三轮；方法插桩与无插桩结果分开保存。
- 覆盖短段、100/1000 段、超长单段、表格，以及行尾和页尾附近。
  模拟序列包含连续拼音、退格、清空、选字、取消和选区替换。
- 输出 handler、布局、位置、绘制耗时的 P50/P95/P99/max，长任务、
  每次合成更新到对应绘制提交的延迟、帧间隔和实际布局次数。
- 被同帧新状态替代的更新须记录为合并，不能记为已经显示，也不能悄悄从分母删除。
  区分接收数、合并数、呈现提交数、最终完成数；结束、取消和销毁都必须排空或失效。
- `requestAnimationFrame`、Canvas 绘制完成和 geometry 都是代理指标；
  自动合成事件不等于真实系统输入法，测试不能伪造 trusted 或人工验收结果。
- handler P95 ≤8ms、geometry P95 ≤32ms 沿用既有预算；增加可见刷新代理指标。
  在 60Hz 测试环境以约 16.7ms 为单帧预算，记录超预算比例，不能承诺所有内容都达标。
  超预算保留 hold；正确性失败直接阻止启用。
- 初始实现保持实验性。任务 05–09 的预览路径在闭环验收前不得默认接管输入。
  不通过关闭中文显示、延迟到选字结束才刷新、遗漏事件或破坏候选窗换取低耗时。

## IME-01：专项基线、事件记录与刷新指标

**目标**：区分输入事件阻塞、布局阻塞、绘制等待和系统候选窗问题。

**入口**：`tests/fixtures/migration/interaction-performance.ts`、
`scripts/test-interaction-performance.mjs`；新增独立 IME fixture/runner，
复用公共测量逻辑，不改写现有 ASCII 基线口径。

**实施**：

1. 记录 compositionstart/update/end、beforeinput/input 的时间、data、
   inputType、isComposing、会话 ID、序号及 trusted 状态。
2. 记录每次更新的模型变更数、布局/绘制次数、阶段耗时、帧间隔及最终文本。
3. 提供确定性的合成事件回放和真实输入法手工录制模式；二者分别标注。
4. 用当前代码建立冻结基线，保留慢样本和原始时序。

**验收**：有可重复命令、环境信息、三轮基线及真实输入法观察记录；
文本/选区检查独立于被测实现；未知的实际屏幕呈现延迟明确标为未测。
临时日志保存到 `cypress/results/ime/`，有效基线按既有数据策略保留。

## IME-02：Demo 配置对照入口

**目标**：确认已实现的同步优化对当前输入法的影响。

**入口**：`src/main.ts`、`src/mock.ts`、`src/editor/utils/performanceProfile.ts`。

**实施**：增加开发/QA 使用的 baseline、sync、worker 配置选择；
profile 与段落缓存独立控制，记录实际生效值。
切换通过销毁和重建完成，不在 composition 中切换，也不制造运行时切换的公共 API。
先让 01 的三轮对照确认差异，再决定日常 Demo 使用哪个配置。

**验收**：相同数据可往返对照、无重复监听或遗留 Worker；
库默认配置保持既有合同；不把开启 sync 记为已经解决 IME。

## IME-03：合成事件归一化与结束去重

**目标**：正确接收连续更新、空值和不同结束顺序，为调度优化提供可靠输入。

**入口**：`core/cursor/CursorAgent.ts`、`core/event/CanvasEvent.ts`、
`core/event/handlers/input.ts`、`core/event/handlers/composition.ts`，均位于 `src/editor/`。

**实施**：

1. 保留 InputEvent 的类型和合成标记，区分空串、null 和真正的删除/取消。
2. 覆盖 compositionend 前后出现最终 input 的不同序列，按会话处理，防止重复提交。
3. 明确 blur、鼠标操作、文档替换和销毁对会话的终止行为。
4. 保留非 IME 输入和移动端删除去重行为；用浏览器实录校验状态转换。

**验收**：连续拼音、退格到空、取消、重复结束、选字提交及选区替换均不丢字、
不重复、不误删；合成结束后状态复位。模拟测试与真实浏览器记录各有证据。

## IME-04：合成会话状态与接口语义

**目标**：将原始范围、最新预编辑内容和最终提交分开管理。

**入口**：`CanvasEvent.ts`、`handlers/composition.ts`、`handlers/input.ts`、
`src/editor/core/history/EditTransaction.ts`；新增内部合成会话模块。

**实施**：会话保存开始时的范围、样式、scope、文档/字体版本、最新文本和序号，
覆盖创建、更新、结束、取消和失效；避免长期保存每个完整拼音版本。
明确合成期间 getValue、几何查询、复制/导出、撤销、插件事件及外部修改的语义，
与现有可见内容和历史行为逐项对照。此任务先建立状态与适配层，保留现有渲染。

**验收**：状态机和接口行为有测试；嵌套表格 scope、选区替换和样式继承可追踪；
旧会话回调不能覆盖新文档；数据不得泄露到持久化文档。

## IME-05：合成刷新调度器与同步屏障

**目标**：一帧内多次合成更新只布局最新状态，限制重复计算。

**入口**：新增内部 composition 调度器；`Draw.ts` 的 requestPaint、flushGeometry、
render 和销毁流程。与 06 联调后才接管实际预览。

**实施**：输入阶段立即记录会话状态，rAF 阶段消费最新序号；
结束、取消、必要几何查询和交互设置明确同步屏障。
隐藏标签页、暂停 rAF、异常和销毁必须有确定的失效或完成策略，
不使用固定 100ms debounce 延迟拼音显示。

**验收**：同帧多次更新只执行一次预览布局；最终状态一定处理；
不依赖过期光标修改模型；暂停帧调度时提交/取消不挂起，销毁后没有残留回调。

## IME-06：局部合成预览布局与绘制

**目标**：连续拼音只更新必要的段落/容器预览，减少正式文档反复替换。

**入口**：`handlers/input.ts`、`Draw.ts`、
`src/editor/core/text-engine-host/LayoutHostAdapter.ts`、
`src/editor/core/text-engine/layout/TextLayoutService.ts`。

**实施**：

1. 建立预编辑内容与原始文档范围的临时映射，使用当前 HarfBuzz 管线排版。
2. 对未变高度的简单正文复用页面和后缀几何，只绘制受影响行/页及合成下划线。
3. 换行、跨页、浮动、复杂控件等不满足条件时执行正确的保守路径。
4. 为 08 提供权威的临时 caret；字体加载或约束变化使预览失效重算。

**验收**：简单正文的同帧合成不重建远端段落；预览与同步参考在文字、
断行、cluster/caret、下划线和像素上符合定义的等价关系；
不回退到浏览器文字测量，复杂范围不使用错误的固定字符窗口。

## IME-07：合成期间派生工作局部更新

**目标**：从每次预编辑刷新中减少非关键工作。

**入口**：`Draw.ts` 的 updateFontCoverage/notifyRender、
`LayoutHostAdapter.collectFontCoverage`、搜索/控件高亮、标尺和 Accessibility。

**实施**：变化范围的字体覆盖及时处理，未变贡献复用；
报告发布、搜索及非关键工具层按帧或结束屏障合并。
保留必要缺字反馈和无障碍输入提示，避免重复 DOM 写读与无效播报；
不通过关闭无障碍功能或字体诊断完成优化。

**验收**：同帧工具层最多刷新一次；缺字、补字体和搜索最终结果正确；
合成结束后派生状态完整，辅助技术反馈可用；报告覆盖阶段及 DOM 布局成本的变化。

**实现记录（2026-10-30）**：`imePreview` 开启时，简单预览及保守回退均只检查
当前合成涉及段落的字体覆盖；已有完整报告用于保留未变文本的下载需求，
临时覆盖仅作为下载工作列表，不向公开 API 发布不完整报告。字体版本或辅助文字配置
变化仍触发完整检查。搜索与控件高亮在预编辑期间暂停重建/绘制，避免旧位置高亮；
标尺、选区样式和工具弹层延后，结束及公开查询/导出屏障补齐，内容/页数事件保留。
简单预览支持无障碍输入反馈，同内容不重复写入 live region，合成反馈不读取 offsetHeight。
默认关闭路径保留原行为；真实屏幕阅读器和系统输入法仍需 IME-14 手动验收。
工作量对照见 [Benchmark](benchmark.md#ime-07-派生工作专项)。

## IME-08：光标、候选窗锚点与滚动同步

**目标**：局部预览与延后布局时，输入法候选窗持续跟随当前合成位置。

**入口**：`src/editor/core/cursor/Cursor.ts`、`CursorAgent.ts`、
Position 临时几何查询及 Draw.setCursor。

**实施**：从当前会话几何定位 textarea 和 caret；同帧合并定位与滚动，
复用容器读数，避免反复 focus、setSelectionRange 和样式写读交错。
覆盖缩放、滚动容器、页尾换行、RTL 混排及表格；不能重置活跃输入法状态。

**验收**：真实输入法候选窗不漂移、不过期、不抢焦点；
滚动、换页和缩放后仍对齐；自动几何断言和手工录制分别保留。

**实现记录（2026-10-30）**：`CompositionAnchor` 在会话消费后的微任务中合并
最新定位，避免再等待一帧；复用一轮容器/祖先滚动端口读数，读完后统一写光标、
textarea 和滚动。两者使用同一份预览或正式 HarfBuzz caret 与累计页偏移。
合成 textarea 使用窄单行输入区和当前 caret 高度，避免固定 30px 高度在缩放后漂移。
不修改 textarea 原生 value/selection，不在合成中 focus；显式 DOM 焦点转移也不会
被延迟 focus 抢回。结束恢复原有输入区样式，销毁使旧微任务失效，并清理 rAF、观察器和监听器。

支持嵌套横纵滚动、RTL 负 scrollLeft、边框偏移、轴对齐 CSS 缩放与平移、DPR 和视口变化。
手动滚动只更新定位，下一次输入或视口尺寸变化再确保 caret 可见。
四个 `executePageScale*` 命令在此实验开启时保留活跃会话，先落实最新预编辑，
再用新缩放重排；其余修改命令保留原有结束屏障。
换行/分页、RTL 和表格继续使用正确的完整布局回退，不新增局部布局支持声明。

自动验收：9 项独立锚点测试及 7 项会话集成测试；Chrome DPR 1/2 ×
局部预览/分页/RTL/表格共 8 场景，断言 textarea/caret 几何、嵌套滚动可见性、
1.5 倍缩放、0.8 倍 CSS transform、原生输入状态保留与焦点不抢回。
页面：`tests/fixtures/migration/ime-anchor.html`；运行：

```bash
BASE_URL=http://127.0.0.1:3020 npm run test:performance:ime:anchors
```

可通过 `PLAYWRIGHT_MODULE` 指定 Playwright 安装路径，`BROWSER_EXECUTABLE` 指定 Chrome。
浏览器结果写入已忽略的 `cypress/results/ime/anchor-geometry.json`。
自动回放为 synthetic 输入，只证明 DOM/几何合同；真实 macOS/Windows 输入法
候选窗、系统缩放和手工录制仍待 IME-14，未将其标记为通过。
手工验收时打开该页面、点击正文，连续输入拼音并缩短/选字，拖动内外滚动条、
调用 `window.imeAnchorQA.scale(1.5)`，录制候选窗跟随及外部按钮焦点保持。

## IME-09：最终提交、取消、历史与查询闭环

**目标**：使新预览路径成为可独立验收的完整编辑功能。

**入口**：composition 会话模块、`Draw.ts` 编辑事务、
`HistoryManager.ts`、查询/导出命令、Worker 镜像和公开事件。

**实施**：选字结束形成一次最终编辑提交；取消恢复开始前选区及内容，
中间预编辑不积累成多份正式历史。落实 04 定义的查询/导出与插件合同，
处理在合成结束前到来的异步字体、外部命令、撤销和 Worker 旧结果。

**验收**：一次 undo 恢复合成前内容、redo 恢复最终结果；
取消零残留，最终导出和 getValue 一致，镜像可排空，事件不重复发布，
销毁无回调；01 基线场景逐项对照后，才允许按应用 opt-in。

**实现记录（2026-11-02）**：

- 默认配置在第一次正式写入前惰性建立一次文档恢复点；增量配置继续使用编辑事务。
  取消恢复正文/页眉页脚/表格或控件内容、选区和输入样式，保留后来注册的字体及缩放。
  不再靠“移除拼音、插回选中文字”推断复杂范围的原始状态；一次取消只做一次恢复渲染。
- 最终渲染、字体覆盖与控件内容的同步回调，在历史提交和旧会话清理后发布，
  屏障内同类回调合并；插件可在最终回调中撤销、读值或开始新会话。
  预编辑回调前先建立 compositionInfo，重入结束不会重复插入或回写旧会话信息。
- 控件移除占位符时，活跃事务内不再弹出上一条历史；最终一次提交可撤销、可重做。
  安全的同 scope/同起点文本替换历史压缩为原始删除片段与最终插入片段；
  Worker 仍接收所有已落实的版本，复杂操作保留快照回退。
- 公开同步查询先落实可见预编辑，异步查询拥有请求时快照；异步导出补齐 graffiti，
  与同步 getValue 的数据合同一致。最终导出不残留临时合成下划线。
- 强制结束的旧原生尾事件抑制持续到原生 end、新 compositionstart 或新 keydown，
  不再依赖 50ms 猜测会话结束；销毁后忽略迟到的 input/composition/keydown。

浏览器验收入口：`npm run test:performance:ime:commit`，默认服务地址
`http://127.0.0.1:3020`，支持 `BASE_URL`、`PLAYWRIGHT_MODULE`、
`BROWSER_EXECUTABLE`。`PROFILES` 和 `SAMPLES` 可缩小复测范围。
回放将异步请求跨过后续输入/最终提交，并检查选区替换、取消、历史、最终事件、
导出、Worker 镜像与队列；单独延迟一个真实 Worker 布局结果到合成结束后再放行，
确认文档和 Canvas 均未被旧结果覆盖。表格保持同步回退，不宣称启用了表格 Worker。
结果写入已忽略的 `cypress/results/ime/commit-closure.json`，不替换历史计时基线。

最终验证：173 文件 / 1133 项单测通过；Chrome 16 场景 / 205 个闭环断言、
旧结果丢弃、8 组锚点与 12 组像素回归通过，ESLint/TypeScript/文档检查通过。

这是 synthetic 自动合同验证；真实输入法顺序、多浏览器、候选窗和手工录制仍待 IME-14。

## IME-10：全局 flow 与位置提交范围缩减

**目标**：减少大文档合成/最终提交对全文规模的依赖。

**入口**：`Draw.computeRowList`、`IncrementalFlow.ts`、
`ParagraphIndex.ts`、`Position.ts`、`NativeQueryIndex.ts`。

**实施**：从首个脏段落开始，满足完整约束的收敛条件后接续后缀；
尽量以块级坐标/索引偏移替代逐元素投影，复用行目录与查询块。
保留宽度、分页、字体、页眉页脚和浮动依赖检查。

**验收**：改变局部内容时远端计算/访问计数下降；
换行与分页慢样本有独立 trace，千段 P95/max 和实际工作量一起报告；
不把原有位置结果复用重复计为新实现，不承诺常数时间全文编辑。

**实现记录（2026-11-02）**：

1. 二分定位首个脏段落；前缀及满足完整 flow 状态的后缀批量接续。
   先验证记录版本、状态链及涉及的每个不同页面（包括段落跨越的中间页），
   再接受整个范围；宽度、分页、字体、页眉页脚、浮动和不支持对象保留检查/回退。
2. 只要未变段落每行的新可用宽度与旧值精确相同，复用断行并重放 DocumentFlow.place，
   不重复进入整段排版；任一行间隔不匹配就丢弃试算、使用完整流程。
   放置后的 native node 使用惰性空间视图，逻辑索引继续投影到规范来源，避免视图链累积。
3. 位置按规范行块附加，只在实际读取时生成索引/行号投影；页缓存保存规范来源。
   大范围几何变化使用普通数组提交，保留安全的度量/源索引复用，避免行块管理反而拖慢。
   诊断入口保持可 structuredClone 的普通位置数组；请求完整快照仍是全文成本。
4. `incrementalCommit` 由 sync/worker profile 启用，显式 false 可只回退本项。
   新增实际检查、显式位置遍历、度量复用、缓存断行重放计数；既有排版/查询块复用
   不作为新增成果。仍需全局目录/页装配、对象扫描与覆盖聚合，不宣称 O(1) 编辑。

千段验证包含不换行、增加换行及跨页三场景；同版本仅切换 incrementalCommit，
其余实验配置相同，三轮固定顺序交替、每场景每档累计 60 次最终提交。
计时为同步 compositionend / 几何提交阶段，不含后续 paint/通知，不是实际呈现或系统 IME FPS。
包含 P95/max、每轮最慢 trace 与实际工作量；结果见 [Benchmark](benchmark.md) 和
[保留的基线/优化汇总](performance-baselines/ime-flow-2026-11-02.json)。

```bash
BASE_URL=http://127.0.0.1:3020 npm run test:performance:ime:flow
```

`TRIALS` / `ITERATIONS` 控制轮数和每轮次数，`CASES=stable,wrap,page` 选择场景；
`OUTPUT` 控制摘要位置。Playwright/浏览器路径变量同 IME-09。
最终验收通过 176 文件 / 1143 项、6 组千段差分，
及既有 16 组闭环、8 组锚点、12 组预览像素检查。

报告只保留各档分布、工作量与最慢样本，不保存逐次原始输入流，不改写历史计时哈希。

## IME-11：超长段落预览几何与断行复用

**目标**：降低一个超长段落中的连续拼音延迟。

**入口**：`TextLayoutEngine.ts`、`TextLayoutService.ts`、
`RunShapeCache.ts`、`LayoutHostAdapter.ts`。

**实施**：先细分段落布局的扫描、度量、对象创建、整形与断行成本，
复用未变行几何；在安全上下文范围内重排，断点及依赖一致后收敛。
BiDi、连写、组合字符、字体切换和两端对齐保留必要回退。

**验收**：固定长段三轮对照；正确性包含 Arabic/CJK/Latin、emoji、组合符；

**已实现**：

1. 原单行预览保留；长段落从正式几何定位编辑行，建立前一行、编辑行、后一行的

   不用“缓存命中”替代正确性校验，也不固定截断上下文后强行接受结果。
3. 只替换编辑行的绘制与候选锚点，其他行继续使用正式几何。

   长段可跨页；实际断行、行高、分页变化仍回退。Arabic、BiDi、度量样式切换、
   两端对齐、表格、装饰和浮动排除保持必要回退。
4. `lab.imeWindowPreview` 由 sync/worker profile 启用，baseline 默认关闭，
   仍需显式开启 `imePreview`。设为 false 可只关闭本项，其他缓存及 IME-01–10 不变。
   窗口建立仍扫描段落，最终提交仍正式布局；本项不声称全流程为常量时间。
5. 可选 `LayoutWork` 采集原生扫描、整形与样式、断行、度量和几何生成耗时，
   并记录实际输入单位、行字形复制数、原生几何项数。
   常规布局不创建采样对象、不读取计时器；插桩测试与无插桩计时独立运行。

## IME-12：表格内合成的单元格增量布局

**目标**：让单元格内拼音更新不必每次重算全表。

**入口**：`TableLayoutHost.ts`、`core/layout/TableLayout.ts`、
`core/draw/particle/table/TablePaging.ts` 及单元格 scope/预览状态。

**实施**：缓存未变单元格；高度不变复用表格几何，
高度变化向关联行、跨行合并和后续分页传播；列宽或全局样式变化完整失效。

**验收**：嵌套/合并/跨页/重复表头均正确，候选窗与光标跟随当前单元格；
记录实际重排单元格和行数，禁止仅凭总耗时波动认定增量生效。

**已实现**：

1. `imeTableLayout` 为正文文本单元格保留规范行/原生节点，复用时更新版本，
   不叠加旧视图链。键包含元素身份、完整语义内容、宽度、scope、方向、缩放、
   字体版本、段落 epoch 与全局布局依赖。字体/列宽/样式变化安全失效。
2. 单元格缓存最多 512 项、估算 16 MiB；单元格最多 4096 元素，销毁清空。
   非文本、有状态控件、区域、浮动等仍执行完整子布局。
   包含嵌套表格的父单元格继续递归，只缓存其中安全的文本叶单元格，避免漏掉深层编辑。
3. 单元格内容高度和表格约束均不变时，沿用规范行高、网格和单元格容器矩形，
   替换最新 children。高度改变时复用未变单元格内容，重新解算表格行高，
   沿用现有 rowspan/colspan、嵌套父级与分页/重复表头传播；不声称此时只重排一行。
4. `tables.computedCells` 计实际子布局回调，`reusedCells` 计跳过的回调；
   `computedRows` / `reusedRows` 区分表格行高/网格的解算与复用。
   `inputElements` 是进入单元格检查/布局的元素数量，非实际堆分配数；
   每次仍检查单元格及其语义键，位置和分页提交仍有全表成本。
5. 开启 `imePreview` 后，sync/worker profile 默认启用此缓存；
   `imeTableLayout: false` 可单独回退，baseline 默认关闭。表格预编辑仍是正式同步
   模型更新，本项不把它改为临时单行预览或异步 Worker 表格布局。

浏览器覆盖 24 行表格、合并单元格、嵌套表格、跨页、重复表头、RTL，
比较每次预编辑的完整语义模型、单元格/位置几何、页面像素及光标，含高度增长/收缩。
超高嵌套内容在原完整路径中也可能找不到有效 caret；未将该极端边界列为通过，
本项不扩展原有嵌套分页能力。

## IME-13：Worker 与合成状态协同

**目标**：在主线程提交成本已降低后，评估迁移纯布局计算的实际收益。

**入口**：`Draw.deferWorkerRender`、`core/worker/layout/`、
`core/text-engine/layout/LayoutKernel.ts`。

**实施**：为支持的预览添加会话/更新序号与版本校验，合并过期计算，
限制传输与缓冲；最终提交和几何消费者保持同步屏障或安全回退。
不能仅删除现有 composition 回退判断；先证明候选窗和最终模型一致。

**验收**：同步与 Worker 结果差分一致，故障/CSP/超限/旧回复可恢复；
主线程长任务、geometry/绘制延迟和排空时间实测改善后才启用。
Worker/transfer 不因本任务自动成为默认配置。

**已实现**：

1. 新增纯 `preview` 请求，传递临时 `NativeParagraphInput` 和合成 generation/sequence，
   不将拼音写入 Worker 正式镜像。服务端复用同一 LayoutKernel，返回同版本 DTO。
2. 客户端保留一个在途布局和一个最新等待布局；替换尚未发出的旧预览。
   同步屏障/结束/销毁取消等待预览，已开始的 HarfBuzz 不强制中断，迟到回复丢弃。
3. 同时核对 Worker session、请求、正式模型/字体/约束版本，主线程几何版本，
   合成会话与更新序号；仍执行 IME-11 原有断点/几何校验后才绘制并更新候选锚点。
   等待期间保留最后一次有效的文本与光标组合，不能把旧回复的 caret 放到新输入上。
4. 预览上限为 2048 元素/4096 UTF-16 单位，继承 4 MiB 等待输入预算，
   返回原生和 shaped 数据合计估算不超过 4 MiB；不自动开启 transfer。
   首个未完成更新保留 50ms 调度后备，过期更新不重置它；失败或到期同步落实最新文本，
   会话后续走正式路径。50ms 不包含主线程被占用的等待，不是硬实时承诺。
5. 查询/导出同步落实最新文本，最终选字/取消/历史仍使用 IME-09 的同步闭环；
   Worker 拒绝、CSP、预算不足、故障、旧回复、连续输入和销毁均有回归。
   诊断 `composition.previewWorker` 区分提交、接受、失效更新、回退、deadline 与 pending。
   `submitted` 是客户端调用数，不等于实际 postMessage 数；`stale` 也包含等待队列被合并的更新。
6. `imeWorkerPreview` 在全部 profile 中默认 false。只有显式设置
   `lab: { performanceProfile: 'worker', imePreview: true, imeWorkerPreview: true }`
   才会尝试迁移已支持的正文局部预览；含表格等不满足原 Worker 镜像条件的文档保留同步路径。
   正式渲染的 composition 回退判断仍保留，没有通过删除判断强行启用 Worker。

```bash
BASE_URL=http://127.0.0.1:3020 npm run test:performance:ime:table-worker
CORRECTNESS_ONLY=1 BASE_URL=http://127.0.0.1:3020 npm run test:performance:ime:table-worker
BASE_URL=http://127.0.0.1:3020 npm run test:performance:ime:table-worker:anchors
```

表格分别测高度稳定与高度变化；Worker 分别测短行和较宽的单行。

## IME-01–06 实现记录

- 测量入口：`scripts/test-ime-performance.mjs`；自动数据明确为 synthetic/untrusted，
  按会话和序号记录事件、合并、几何提交代理、rAF、绘制及布局次数。
  `INSTRUMENTATION=off` 可采集独立的无方法包装对照。
- QA 页面：`tests/fixtures/migration/ime-performance.html`；可手工开始真实输入法记录，
  结束后下载 JSON。URL 的 `inputMethod` 参数用于填写实际输入法名称和版本；
  原始记录包含测试文本，勿录入敏感内容。真实候选窗需人工另行观察和录屏。
- Demo 通过 URL 的 `performance=baseline|sync|worker`、
  `paragraphCache=on|off`、`imePreview=on|off` 独立选择构造配置。
  重载页面完成切换；没有参数时保留原默认配置。
- 新增 `lab.imePreview`，默认 false，不随 profile 自动开启。
  预编辑状态每帧消费最新值，暂停 rAF 时有 50ms 的排空后备，
  它不是对每次输入设置 50ms debounce，也不是硬性刷新保证。
- 局部路径仅支持简单 LTR 正文单行、行高/基线不变、至多 2048 元素的段落。
  使用 HarfBuzz 的临时行、当前页面放置和原页面绘制顺序，不修改正式元素。
  页内仍重绘所在页面，尚未实现 Tile 或任意多行局部重绘。
- 换行、跨页、BiDi 复杂范围、表格、控件、列表、装饰、可见格式标记、
  开启无障碍、设置输入默认样式或文档含浮动/图片排布等不满足条件时，按帧执行原同步路径；这些范围不宣称局部布局已实现。
- input 是合成文本的权威来源，compositionupdate 只记录事件。
  空值删除读取必要的 textarea 状态，处理结束前后 input 的去重与迟到结果。
  原生候选窗导致的无 DOM 目标 blur 不强制结束会话。
- 公开内容/几何查询先落实当前预编辑，后续更新转入同步回退；
  公开执行命令先结束会话；实际选字一次提交，取消恢复原内容与范围。
  中间局部预览不发布正式内容变化事件；预览查询不是新持久化协议。
- 定向覆盖提交/取消/撤销、空值、重复结束、强制结束后的迟到事件、
  非首段和 CJK 几何、换行回退、暂停 rAF 与销毁。
  `scripts/test-ime-preview.mjs` 逐像素对照同步参考，不仅核对最终文字。

复现命令（需独立 Playwright 和相应浏览器，配置方法沿用测试与验收）：

```sh
rtk npm run dev -- --host 127.0.0.1 --port 3014 --strictPort

BASE_URL=http://127.0.0.1:3014 TRIALS=3 INTERVAL_MS=33 \
rtk node scripts/test-ime-performance.mjs

BASE_URL=http://127.0.0.1:3014 rtk node scripts/test-ime-preview.mjs
```

性能采集与单测、构建串行执行。默认矩阵为五种文档、baseline/sync、
预览关闭/开启及三轮；每轮 7 次预编辑，含缩短再输入，最终选字为“你好”。
33ms 为模拟更新间隔，不代表系统输入法实际发送频率。
报告分别列出 preedit 阶段和整个提交/历史闭环的工作量，
`updateToGeometryProxy` 和 `updateToNextRaf` 均不代表真实上屏延迟。
中间状态被合并时标为 merged，不能声称每次状态都已显示。


验证口径补充：自动矩阵的 `frameGaps` 覆盖整个提交/历史闭环。
分析合成刷新时，应从原始 frames 中只选择 compositionstart 到 compositionend
之间的帧，单独计算间隔，不能把最终提交或 undo/redo 的耗时混入预编辑刷新率。
局部预览与同步参考采用相同的单实线合成下划线；逐像素检查同时覆盖了文字和下划线。

最终自动对照为 60 场景/420 次预编辑，另有无方法插桩 12 场景/84 次；像素差分 12/12。结果及限制统一见 [Benchmark 的 IME 专项结果](benchmark.md)。系统输入法人工证据仍未完成。
