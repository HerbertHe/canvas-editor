## 同一份 100 段文档

三套页面载入相同的英语和阿拉伯语混排正文，在文档中部编辑。固定纸张为 480 × 640 CSS px，
四边页边距为 32 px，字号 16，缩放 100%。测试前的正文有 7,699 个 UTF-16 单元。
上游、初始迁移和当前版本的页数分别为 13、19 和 19。
各版本沿用自己的字体解析和排版方式，实际分页可不同。

| 指标 | 上游在线示例 | 初始迁移基准 | 当前版本 |
| --- | ---: | ---: | ---: |
| 输入处理 | 3.2 / 5.3 | 418.2 / 573.8 | 7.0 / 8.3 |
| Backspace 处理 | 3.7 / 5.2 | 412.4 / 460.2 | 6.5 / 8.3 |
| Delete 处理 | 3.0 / 6.6 | 417.5 / 503.7 | 6.9 / 9.1 |
| IME 预编辑处理 | 3.1 / 3.8 | 418.4 / 473.2 | 0.0 / 0.1 |

共享样本的 Backspace 处理 P95 从初始迁移的 **460.2 ms** 降到当前版本的
**8.3 ms**，上游为 **5.2 ms**。内置示例的 IME 预编辑到第二次帧回调 P95
分别为上游 **32.4 ms**、初始迁移 **135.1 ms**、当前版本 **31.6 ms**。
当前内置示例的 Backspace 处理中位数为 **6.6 ms**，P95 为
**49.7 ms**，慢样本仍明显拉长尾延迟。

## 测量口径与复现

- 视口 1366 × 720，DPR 1。每轮预热一次键入和删除，再分别回放 12 次输入、Backspace
  和 Delete，以及 7 次拼音预编辑，最后提交「你好」。键盘操作由浏览器生成，驱动每次
  等上一条命令完成，间隔至少 50 ms。拼音预编辑通过 Chrome 的合成接口回放，间隔至少 40 ms。
- 输入和预编辑计时取 `input` 事件处理用时，删除取 `keydown`。第二次
  `requestAnimationFrame` 记录浏览器调度延迟，屏幕呈现、真实系统输入法候选窗和硬件按键重复
  不在本次计量范围内。
- 18 轮均核对事件数量、最终正文和光标位置。每个目标每种样本的每项键盘指标有 36
  次事件，IME 预编辑指标有 21 次事件。
