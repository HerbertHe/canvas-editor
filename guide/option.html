配置 ​

@herberthe/canvas-editor@0.1.0：默认且仅 Canvas 页面绘制；SVG 实现与导出暂缓，无 renderer 切换配置。参见项目关系与差异。

使用方式 ​

javascript
import Editor from '@herberthe/canvas-editor'

const editor = await Editor.create(container, data, {
  // 配置项
})

文字统一使用 HarfBuzz，textEngine / renderMode 及对应枚举已删除。 传入旧键会抛出迁移错误。autoDownloadFonts 默认为 true；关闭后仍显示缺字提示。 fonts 不会读取操作系统字体，运行期补字体使用 register.fonts。 详见字体与 ESM 迁移。
