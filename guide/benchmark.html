同一份 100 段文档 ​

三套页面载入相同的英语和阿拉伯语混排正文，在文档中部编辑。固定纸张为 480 × 640 CSS px， 四边页边距为 32 px，字号 16，缩放 100%。测试前的正文有 7,699 个 UTF-16 单元。 上游、初始迁移和当前版本的页数分别为 13、19 和 19。 各版本沿用自己的字体解析和排版方式，实际分页可不同。

测量口径与复现 ​

  • 视口 1366 × 720，DPR 1。每轮预热一次键入和删除，再分别回放 12 次输入、Backspace 和 Delete，以及 7 次拼音预编辑，最后提交「你好」。键盘操作由浏览器生成，驱动每次 等上一条命令完成，间隔至少 50 ms。拼音预编辑通过 Chrome 的合成接口回放，间隔至少 40 ms。
  • 输入和预编辑计时取 input 事件处理用时，删除取 keydown。第二次 requestAnimationFrame 记录浏览器调度延迟，屏幕呈现、真实系统输入法候选窗和硬件按键重复 不在本次计量范围内。
  • 18 轮均核对事件数量、最终正文和光标位置。每个目标每种样本的每项键盘指标有 36 次事件，IME 预编辑指标有 21 次事件。

本次三组原始日志 · 2026-10-22 初始迁移历史日志

当前版本可用 npm run docs:build 构建。初始迁移通过 git archive c5a00d38 导出到 临时目录，复用项目的依赖并用 DOCS_BASE=/initial/ node scripts/build-docs-demo.mjs 打包。用静态服务分别提供两个构建，并按构建时的基路径设置下列 URL。

sh
PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs \
BROWSER_EXECUTABLE='/Applications/Google Chrome.app/Contents/MacOS/Google Chrome' \
INITIAL_URL=http://127.0.0.1:3027/initial/playground/ \
CURRENT_URL=http://127.0.0.1:3027/canvas-editor/playground/ \
node scripts/test-playground-benchmark.mjs
