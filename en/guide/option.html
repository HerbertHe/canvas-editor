Configuration ​

@herberthe/canvas-editor@0.1.0: Canvas is the default and only page renderer. SVG implementation/export is deferred; no renderer selector exists. See fork differences.

How to Use? ​

javascript
import Editor from '@herberthe/canvas-editor'

const editor = await Editor.create(container, data, {
  // option
})

All text uses HarfBuzz. textEngine, renderMode and their enums have been removed; passing old keys throws a migration error. autoDownloadFonts defaults to true. Disabling it retains missing-font hints. Supply bytes/URLs through fonts, and use register.fonts at runtime; system fonts alone are insufficient. See Fonts and ESM migration.
