# 能力与支持边界

本页概述当前独立 fork 的能力，具体字段以[配置](./option.md)和命令参考为准。继承自上游的功能与新增排版能力分别在[项目关系](./fork-and-differences.md)列出，避免把既有功能误认为本 fork 原创。

| 领域       | 当前支持                                                                       | 接入边界                                          |
| ---------- | ------------------------------------------------------------------------------ | ------------------------------------------------- |
| 文字排版   | HarfBuzz 整形、BiDi、复杂文字、真实字体覆盖与字形轮廓                          | 不承诺所有文种、样式与 emoji 完整验证；需字体文件 |
| 富文本     | 字体字号、粗斜体、颜色、高亮、上下标、装饰、标题、对齐、列表、缩进、行距与段距 | 字重/样式需要实际 face；字体度量可能改变分页      |
| 页面       | 分页/连页、页边距、分栏、页眉页脚、页码、行号、边框、水印                      | 页面固定 Canvas；DOM 工具层仍存在                 |
| 表格       | 行列操作、合并拆分、边框背景、对齐、跨页分片                                   | 复杂表格仍需按业务数据回归                        |
| 图片与对象 | 图片、浮动图、链接、公式、日期、Tab、分页符和内容块                            | 外部资源受加载、CORS 与导出限制                   |
| 表单控件   | 文本、数字、下拉、单选、复选、日期、嵌套、禁用与级联校验                       | 详见控件 API；工具界面由宿主组装                  |
| 编辑交互   | 选区、光标、撤销重做、搜索替换、快捷键、右键菜单、拖拽                         | 光标/删除语义可配置，UI 方向不等于内容方向        |
| 文档业务   | 批注、留痕、区域、目录、宏、国际化与模式切换                                   | 上游插件需单独验证                                |
| 字体管理   | TTF/OTF/WOFF/WOFF2、缺字报告与事件、Bunny 基本字体自动下载                     | 默认开启；可离线关闭并手动提供；不是完整字库      |
| 导出与打印 | JSON、HTML/文字查询、Canvas PNG 页面与浏览器图片打印                           | 无独立 SVG 页面导出、无原生矢量 PDF 保证          |
| 分发       | ESM 包根导出、TypeScript 声明、异步 ready                                      | 无 UMD / require / 内部深路径兼容                 |

## 性能与实验项

`lab.incrementalCompute` 默认关闭。它复用未变化段落，仍执行全局流、分页和位置更新；不是只修改 Canvas 局部像素的通用优化。T23/T24 已完成回归，但性能仍有后续工作，开启增量不保证更快。参见[增量边界](./lab.md)和[最终验收](./native-release-acceptance.md)。

## 暂缓与不提供的能力

SVG 页面后端与独立 SVG 导出暂缓，仅保留[设计评估](./harfbuzz-svg-assessment.md)。没有引擎切换配置或 legacy 回退。安装包本身不提供业务服务器、协同 CRDT、原生 Word/PDF 排版引擎，也不自动安装上游插件。文档中的未来设计与历史迁移步骤不代表当前公开 API。
